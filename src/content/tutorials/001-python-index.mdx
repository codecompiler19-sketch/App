# Python Tutorial

Python is easier to learn when you write small programs, run them, and change them. This tutorial is the starting point for the Python series on CodesCompiler.

The goal is not to memorize every keyword. Instead, learn what each part of a program does, practice it immediately, and gradually combine simple ideas into useful programs.

## Your First Python Program

Start with a complete program:

```python
name = "Python learner"
language = "Python"

print("Hello,", name)
print("You are learning", language)
```

### Output

```text
Hello, Python learner
You are learning Python
```

This small program introduces two ideas that you will use constantly:

- A **variable** gives a value a name.
- `print()` displays a value in the program's output.

Change `name` and run the program again. Small experiments like this are one of the fastest ways to build confidence.

## Why Learn Python?

Python is a general-purpose language used in many areas of software development, including:

- automation and scripting
- web applications and backend services
- APIs and developer tools
- data analysis
- testing
- scientific computing
- machine learning and AI
- desktop utilities

You do not need to choose a specialization immediately. First build a solid understanding of the language, then apply it to the area that interests you.

## Learn by Changing Working Code

For every new concept, use this simple practice cycle:

1. **Read** the explanation.
2. **Run** the example as written.
3. **Change** one value or statement.
4. **Solve** a small variation without looking at the answer.

For example, you can make a program interactive with `input()`:

```python
name = input("What is your name? ")
print("Welcome,", name)
```

Try extending it by asking for a favorite programming language or another piece of information. Then make the program use both answers.

## Variables and Values

A variable gives a value a name:

```python
age = 20
course = "Python"

print(age)
print(course)
```

Python determines the type of a value at runtime. You can inspect the type with `type()`:

```python
value = 42
print(type(value))
```

Continue with [Python Variables](/tutorial/python-variables/) and [Python Data Types](/tutorial/python-data-types/) to learn more.

## Conditions

An `if` statement lets a program choose what to do:

```python
score = 72

if score >= 50:
    print("Pass")
else:
    print("Try again")
```

Python uses indentation to define the statements inside a block. Consistent indentation is therefore part of writing valid Python code.

Continue with [Python if Statement](/tutorial/python-if-statement/) and [Python if-else](/tutorial/python-if-else/).

## Loops

A loop repeats a block of code. For example, `range(1, 6)` produces the values 1 through 5:

```python
for number in range(1, 6):
    print(number)
```

### Output

```text
1
2
3
4
5
```

Continue with [Python for Loops](/tutorial/python-for-loops/) and [Python while Loops](/tutorial/python-while-loops/).

## Lists

A list stores multiple values in one ordered collection:

```python
languages = ["Python", "JavaScript", "SQL"]

for language in languages:
    print(language)
```

### Output

```text
Python
JavaScript
SQL
```

Lists are used throughout Python programs. After learning the basics, explore [Python Lists](/tutorial/python-lists/) and the related tutorials on accessing, changing, sorting, and comprehending lists.

## Handling Errors

Real programs can receive invalid input, encounter missing files, or fail for other reasons. Python uses exceptions to represent many runtime errors.

For example:

```python
try:
    number = int(input("Enter a number: "))
    print("Double:", number * 2)
except ValueError:
    print("Please enter a valid integer.")
```

If the user enters `abc`, the conversion raises `ValueError` and the program prints the friendly error message instead of stopping with an unhandled exception.

Learn more in [Python Exceptions](/tutorial/python-exceptions/).

## Working with Files

Python can read and write files, which is useful for scripts, reports, data processing, and automation.

```python
with open("notes.txt", "w", encoding="utf-8") as file:
    file.write("Python makes file handling straightforward.")
```

The `with` statement manages the file resource for you and closes the file when the block finishes.

Continue with [Python File Handling](/tutorial/python-file-handling/) and [Python Read Files](/tutorial/python-read-files/).
