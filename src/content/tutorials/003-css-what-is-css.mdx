# CSS - Introduction

CSS (Cascading Style Sheets) is the language used to control how HTML content looks and how it is laid out on a web page. HTML gives a page its structure; CSS controls the presentation of that structure.

With CSS, you can change colors, fonts, spacing, borders, backgrounds, alignment, responsive layouts, and much more without changing the meaning or structure of the HTML.

## What is CSS?

CSS stands for **Cascading Style Sheets**.

A CSS rule tells the browser which HTML elements to target and which styles to apply. For example:

```css
p {
  color: darkblue;
  font-size: 18px;
}
```

This rule targets every `<p>` element and makes its text dark blue with an 18-pixel font size.

CSS can be written in a separate stylesheet, inside a `<style>` element, or directly on an HTML element with the `style` attribute. In real projects, external stylesheets are usually preferred because they keep structure and presentation separate and make styles easier to reuse.

## HTML and CSS Work Together

Think of a web page as a house:

- **HTML** provides the structure, such as headings, paragraphs, buttons, and sections.
- **CSS** controls the appearance, such as colors, spacing, borders, and layout.
- **JavaScript** can add behavior, such as responding to clicks or updating content.

Here is a small HTML document with CSS:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <style>
    h1 {
      color: #1d4ed8;
    }

    p {
      line-height: 1.6;
    }
  </style>
</head>
<body>
  <h1>Welcome to CSS</h1>
  <p>CSS makes HTML pages easier to read and more attractive.</p>
</body>
</html>
```

The HTML provides the content, while the CSS rules determine how that content is displayed.

## Why Use CSS?

CSS is important because it makes web pages easier to build, maintain, and adapt.

### 1. Reuse styles

A single stylesheet can style many HTML pages. You do not need to repeat the same declarations in every document.

### 2. Keep structure and presentation separate

HTML can focus on meaningful content and structure while CSS handles visual presentation. This separation makes both easier to maintain.

### 3. Make global changes quickly

If several pages use the same stylesheet, changing one CSS rule can update the appearance of many elements at once.

### 4. Build responsive layouts

CSS provides tools such as media queries, flexible units, Flexbox, and Grid for creating layouts that work across phones, tablets, and desktop screens.

### 5. Create accessible, readable interfaces

Good CSS can improve spacing, typography, contrast, focus states, and responsive behavior without changing the underlying semantic HTML.

## CSS Syntax

A basic CSS rule has a **selector** followed by a **declaration block**:

```css
selector {
  property: value;
}
```

For example:

```css
h1 {
  color: navy;
  margin-bottom: 12px;
}
```

Here is what each part means:

- `h1` is the **selector**. It targets `<h1>` elements.
- `{ ... }` is the **declaration block**.
- `color` and `margin-bottom` are **properties**.
- `navy` and `12px` are the corresponding **values**.
- Each declaration normally ends with a semicolon.

You can put multiple declarations in the same rule:

```css
.card {
  padding: 20px;
  background-color: white;
  border: 1px solid #ddd;
}
```

CSS has many kinds of selectors, including element, class, ID, attribute, pseudo-class, and pseudo-element selectors. You will learn them in more detail in the CSS Selectors section.

## How CSS Cascades

The word **cascading** describes how the browser resolves multiple CSS rules that apply to the same element.

For example, if two rules set the color of the same paragraph, the browser considers factors such as origin, importance, specificity, and source order when deciding which declaration wins.

A simple example of source order is:

```css
p {
  color: blue;
}

p {
  color: green;
}
```

Both rules target the same paragraphs. Because the selectors have the same specificity and the second declaration appears later, the paragraph will normally be green.

Specificity and the cascade become especially important as a stylesheet grows.

## Ways to Add CSS

There are three common ways to apply CSS.

### External CSS

An external stylesheet is stored in a separate `.css` file and linked from HTML:

```html
<link rel="stylesheet" href="styles.css">
```

This is generally the best choice for multi-page websites because the same stylesheet can be reused.

### Internal CSS

CSS can be placed inside a `<style>` element:

```html
<style>
  body {
    font-family: Arial, sans-serif;
  }
</style>
```

Internal CSS can be useful when styles are specific to a single HTML document.

### Inline CSS

CSS can also be written directly on an HTML element:

```html
<p style="color: crimson;">Important message</p>
```

Inline styles are useful for very specific cases, but they are usually harder to maintain when used throughout a project.

## CSS History and Modern CSS

CSS has evolved significantly since its early specifications.

- **CSS1** was published as a W3C Recommendation in 1996 and established the foundation of the language.
- **CSS2** followed in 1998 and added capabilities such as positioning, media-specific styles, and more advanced presentation features.
- **CSS3** introduced a modular approach in which individual specifications could evolve independently.

It is more accurate to think of modern CSS as a collection of continuously evolving modules rather than a single language version called \"CSS3\". Features such as Grid, Flexbox, animations, custom properties, media queries, and CSS nesting have been added through separate specifications.

## Common Beginner Mistakes

### Forgetting the semicolon

This is easy to miss when writing several declarations:

```css
p {
  color: blue;
  font-size: 18px;
}
```

Although the final semicolon can sometimes be omitted, keeping semicolons consistently makes your CSS easier to edit and reduces mistakes.

### Confusing a class with an element selector

A class selector starts with a dot:

```css
.notice {
  color: orange;
}
```

It targets HTML such as:

```html
<p class="notice">Read this message.</p>
```

An element selector does not use a dot:

```css
p {
  color: orange;
}
```

### Using IDs for reusable styling

An ID should identify a unique element in a document. For reusable styles, classes are usually a better choice:

```css
.button {
  padding: 10px 16px;
}
```

### Writing overly specific selectors

Very specific selectors can make styles difficult to override later. Prefer simple, reusable selectors when possible.

## CSS Best Practices

- Use meaningful class names.
- Prefer external stylesheets for shared styles.
- Keep selectors as simple as practical.
- Use responsive units and layouts where appropriate.
- Use CSS variables for values that are reused.
- Avoid unnecessary inline styles.
- Keep related rules organized and easy to scan.
- Test layouts at different screen sizes.
- Use sufficient color contrast and visible keyboard focus states.
- Validate your HTML so CSS is applied to a predictable document structure.
