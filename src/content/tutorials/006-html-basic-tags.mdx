# HTML Basic Tags: A Guide for Complete Beginners with Examples

HTML tags are the building blocks of an HTML document. They tell the browser what each piece of content represents, such as a heading, paragraph, list, or thematic break.

Most elements use an opening tag and a closing tag:

```html
<p>This is a paragraph.</p>
```

Some HTML elements are **void elements**, which do not have closing tags. Common examples include `<br>`, `<hr>`, `<img>`, and `<input>`.

In this tutorial, you'll learn the basic tags you'll use frequently when creating HTML pages, along with practical examples and a few important HTML5 conventions.

## Heading Tags

HTML provides six heading levels, from `<h1>` through `<h6>`. Use headings to describe the structure of your content, not simply to make text look larger.

- `<h1>` is normally the main heading of a page.
- `<h2>` introduces a major section.
- `<h3>` and the remaining levels represent progressively nested sections.

### Example

```html
<!DOCTYPE html>
<html>
<head>
  <title>Heading Example</title>
</head>
<body>
  <h1>HTML Basics</h1>
  <h2>HTML Elements</h2>
  <h3>Heading Elements</h3>
  <h4>Details</h4>
  <h5>Additional Notes</h5>
  <h6>Smallest Heading Level</h6>
</body>
</html>
```

The browser gives each heading a default visual style, but you should use CSS when you need to change its size, spacing, or appearance.

## Paragraph Tag

The `<p>` element represents a paragraph of text. Keep separate ideas or blocks of prose in separate paragraph elements.

### Example

```html
<!DOCTYPE html>
<html>
<head>
  <title>Paragraph Example</title>
</head>
<body>
  <p>HTML gives a page its structure.</p>
  <p>CSS controls presentation and layout.</p>
  <p>JavaScript can add behavior and interaction.</p>
</body>
</html>
```

A browser automatically places paragraphs on separate lines and applies default spacing. For custom spacing, use CSS rather than adding empty paragraphs.

## Line Break Tag

The `<br>` element inserts a line break inside the current flow of text. It is useful when the line break itself is meaningful, such as in an address, poem, or short piece of formatted text.

`<br>` is a void element, so it does not have a closing tag.

### Example

```html
<!DOCTYPE html>
<html>
<head>
  <title>Line Break Example</title>
</head>
<body>
  <p>
    CodeCompiler<br>
    New Delhi<br>
    India
  </p>
</body>
</html>
```

Do not use repeated `<br>` elements to create page spacing. Use CSS margins and padding for layout.

## Centering Content

The old `<center>` element is obsolete in modern HTML and should not be used. Center content with CSS instead.

For example, the `text-align: center` property can center text inside its containing element:

```html
<!DOCTYPE html>
<html>
<head>
  <title>Centering Content Example</title>
  <style>
    .center-text {
      text-align: center;
    }
  </style>
</head>
<body>
  <p>This paragraph uses the normal alignment.</p>
  <p class="center-text">This paragraph is centered with CSS.</p>
</body>
</html>
```

CSS can also be used to center larger page sections with modern layout techniques such as Flexbox and Grid.

## Horizontal Rule Tag

The `<hr>` element represents a thematic break between sections of content. Browsers usually display it as a horizontal line, but its meaning is more important than its default appearance.

`<hr>` is a void element, so it does not need a closing tag.

### Example

```html
<!DOCTYPE html>
<html>
<head>
  <title>Horizontal Rule Example</title>
</head>
<body>
  <h2>Introduction</h2>
  <p>This section introduces the topic.</p>

  <hr>

  <h2>Next Section</h2>
  <p>This section contains related information.</p>
</body>
</html>
```

You can style the rule with CSS when the default appearance does not match your design.

In HTML5, write the element as `<hr>`. The XHTML-style `<hr />` syntax is also commonly encountered, but the slash is not required in HTML.

## Preserve Formatting Tag

The `<pre>` element represents preformatted text. Whitespace, line breaks, and indentation inside a `<pre>` element are preserved by the browser.

It is useful for content such as terminal output, configuration snippets, or simple text where spacing is meaningful.

### Example

```html
<!DOCTYPE html>
<html>
<head>
  <title>Preserve Formatting Example</title>
</head>
<body>
  <pre>
function greet(name) {
  console.log("Hello, " + name);
}
  </pre>
</body>
</html>
```

For source code, it is common to combine `<pre>` with `<code>`:

```html
<pre><code>function greet(name) {
  console.log("Hello, " + name);
}</code></pre>
```

The `<pre>` element preserves whitespace, while `<code>` identifies the content as computer code.

## Non-breaking Spaces

A normal space can be collapsed by HTML's rendering rules, while the non-breaking space entity `&amp;nbsp;` represents a space that should not be used as a line-breaking opportunity.

A common use is keeping a short phrase together. For example, a product name or name-and-number combination may benefit from a non-breaking space.

### Example

```html
<!DOCTYPE html>
<html>
<head>
  <title>Non-breaking Space Example</title>
</head>
<body>
  <p>The movie is called 12&nbsp;Angry&nbsp;Men.</p>
</body>
</html>
```

The browser displays the non-breaking spaces as normal visible spaces, but it will avoid breaking the line at those spaces when wrapping the text.

Avoid using many non-breaking spaces for indentation or page layout. Use CSS for layout and spacing instead.

## Listing Tags

HTML provides several elements for creating lists. The most common are:

- `<ul>` for an unordered list, where item order is not important.
- `<ol>` for an ordered list, where sequence matters.
- `<li>` for each list item.

### Unordered List Example

```html
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
```

This produces a bulleted list.

### Ordered List Example

```html
<ol>
  <li>Open your code editor.</li>
  <li>Create an HTML file.</li>
  <li>Open the file in a browser.</li>
</ol>
```

This produces a numbered list.

A complete page can combine both list types:

```html
<!DOCTYPE html>
<html>
<head>
  <title>List Example</title>
</head>
<body>
  <h1>Learning Plan</h1>

  <h2>Topics</h2>
  <ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
  </ul>

  <h2>First Steps</h2>
  <ol>
    <li>Create an HTML file.</li>
    <li>Add your page structure.</li>
    <li>Open the page in a browser.</li>
  </ol>
</body>
</html>
```

Lists are useful for navigation, instructions, features, menus, and many other types of structured content. Choose the list element based on the meaning of the content rather than its visual appearance.
